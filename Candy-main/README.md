# Candy

تطبيق كاندي: الواجهة الاجتماعية لحساب كندا (Kanade).
نفس الحسابات والهاشات ونفس سيرفر البوت، والتطبيق مجرد واجهة له.

## إزاي بيتبني
- كل push على `main` بيشغّل GitHub Actions وبيطلع APK في Releases.
- لتحديث التطبيق من الموبايل: ارفع `update.zip` في جذر الريبو (نفس طريقة كانا).

## عنوان السيرفر
ملف `api-url.txt` في جذر الريبو فيه عنوان البوت (HTTPS) في سطر واحد.
لو فاضي أو مش موجود، التطبيق بيكلم البوت على نفس الموبايل (`127.0.0.1:8787`).

## الأيقونة ومفتاح التوقيع
محفوظين كنص base64 (`icon.b64` و`debug.keystore.b64`) وبيتفكوا وقت البناء.

## البوت
محتاج `candyApi.js` و`appApi.js` و`avatarCore.js` الجداد في فولدر `lib` بتاع البوت.
